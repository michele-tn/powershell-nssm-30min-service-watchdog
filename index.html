01 / Overview

What the automation does

The corrected PowerShell automation validates prerequisites, replaces an existing NSSM service, deploys the executable locally, enables unattended recovery, and registers a SYSTEM scheduled task that restarts the service every 30 minutes.

01

Fail fast

Stops on errors and checks administrator rights, NSSM, Windows PowerShell, and the source executable before deployment.

02

Replace safely

Stops and removes an existing service, then waits with a bounded timeout for Windows to confirm deletion.

03

Install locally

Copies the release artifact into a dedicated ProgramData runtime directory.

04

Restart predictably

NSSM restarts unexpected exits; Task Scheduler forces a controlled restart every 30 minutes.

Destructive behavior: a service with the configured name is stopped and removed. Verify the exact target and use an approved maintenance window.

04 / Deployment

Controlled installation

1. Stage

Install a verified NSSM build, authorize read access to the release share, and confirm the application runs non-interactively.

2. Customize

Set the name, paths, identity, logging, and recovery values for the target environment.

3. Validate

Use a test host, check for naming collisions, back up configuration, and document rollback.

4. Run elevated

Execute the reviewed local script from a trusted Administrator PowerShell session.

# Inspect release artifacts before execution
Get-AuthenticodeSignature .\deploy-service.ps1
Get-FileHash .\Application.exe -Algorithm SHA256

# Use a process-scoped policy only
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\deploy-service.ps1

Validate signatures or hashes through an independent trusted channel. Do not weaken the machine-wide execution policy.

06 / Security

Production hardening

Use least privilege

LocalSystem has extensive rights. Prefer a dedicated service account or gMSA with only required permissions.

Protect the supply chain

Pin NSSM, verify checksums, sign the script, and validate the application artifact before copying.

Control write access

Restrict the share and installation directory. A writable executable path can enable privilege escalation.

Keep secrets out

Never publish credentials, internal hostnames, customer identifiers, production paths, or private IP addresses.

07 / Corrected implementation

Complete production script

This anonymized, ready-to-customize version combines NSSM crash recovery with an independent SYSTEM scheduled task that forces a service restart every 30 minutes.

Customize before use: review the source share, installation directory, service identity, executable name, and NSSM location for the target environment.
# deploy-application-service.ps1
# Run from an elevated PowerShell session

$ErrorActionPreference = "Stop"

$NSSM = "C:\Tools\nssm\win64\nssm.exe"
$ServiceName = "ApplicationService"
$RestartTaskName = "$ServiceName-Restart-Every-30-Minutes"
$RestartIntervalMinutes = 30

$SourceExecutable = "\\\\fileserver.example\\deploy\\Application\\Application.exe"
$InstallDirectory = "C:\ProgramData\ExampleOrg\Application"
$InstalledExecutable = Join-Path $InstallDirectory "Application.exe"

# Log paths used by NSSM for rotation
$LogStdout = Join-Path $InstallDirectory "stdout.log"
$LogStderr = Join-Path $InstallDirectory "stderr.log"

function Invoke-Nssm {
    param(
        [Parameter(Mandatory)]
        [string[]] $NssmArguments
    )

    & $NSSM @NssmArguments
    $exitCode = $LASTEXITCODE

    if ($exitCode -ne 0) {
        throw (
            "NSSM returned exit code {0}: {1}" -f `
                $exitCode,
                ($NssmArguments -join " ")
        )
    }
}

# Administrator privilege check
$isAdministrator = (New-Object Security.Principal.WindowsPrincipal([Security.Principal.WindowsIdentity]::GetCurrent())).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
if (-not $isAdministrator) {
    throw "Run this script from an elevated PowerShell session."
}

if (-not (Test-Path -LiteralPath $NSSM -PathType Leaf)) {
    throw "NSSM not found: $NSSM"
}

if (-not (Test-Path -LiteralPath $SourceExecutable -PathType Leaf)) {
    throw "Source executable not found or inaccessible: $SourceExecutable"
}

if (-not (Test-Path -LiteralPath $InstallDirectory -PathType Container)) {
    New-Item -ItemType Directory -Path $InstallDirectory -Force | Out-Null
}

# Safely replace an existing service
$existingService = Get-Service -Name $ServiceName -ErrorAction SilentlyContinue
if ($existingService) {
    Write-Host "Stopping existing service: $ServiceName"
    if ($existingService.Status -ne "Stopped") {
        # Do not block indefinitely when the service is already stopping
        try {
            Invoke-Nssm @("stop", $ServiceName)
        } catch {
            Write-Host "The service is taking time to stop; continuing with removal..."
        }
        Start-Sleep -Seconds 3
    }

    Write-Host "Removing existing service..."
    Invoke-Nssm @("remove", $ServiceName, "confirm")

    $waitCount = 0
    while (Get-Service -Name $ServiceName -ErrorAction SilentlyContinue) {
        $waitCount++
        if ($waitCount -gt 24) {
            throw "Service $ServiceName is still pending deletion. Close services.msc or restart Windows."
        }
        Write-Host "Waiting for service removal..."
        Start-Sleep -Seconds 5
    }
}

Write-Host "Copying the executable..."
Copy-Item -LiteralPath $SourceExecutable -Destination $InstalledExecutable -Force

if (-not (Test-Path -LiteralPath $InstalledExecutable -PathType Leaf)) {
    throw "Executable copy failed: $InstalledExecutable"
}

Write-Host "Installing standalone service: $ServiceName"
Invoke-Nssm @("install", $ServiceName, $InstalledExecutable)
Invoke-Nssm @("set", $ServiceName, "AppDirectory", $InstallDirectory)
Invoke-Nssm @("set", $ServiceName, "ObjectName", "LocalSystem")
Invoke-Nssm @("set", $ServiceName, "Start", "SERVICE_AUTO_START")
Invoke-Nssm @("set", $ServiceName, "AppNoConsole", "1")

# Reindirizzamento dell'output (Condizione fondamentale per la rotazione di NSSM)
Invoke-Nssm @("set", $ServiceName, "AppStdout", $LogStdout)
Invoke-Nssm @("set", $ServiceName, "AppStderr", $LogStderr)

# Rotate eligible logs when the service starts or restarts
Invoke-Nssm @("set", $ServiceName, "AppRotateFiles", "1")
Invoke-Nssm @("set", $ServiceName, "AppRotateSeconds", "1800")

# Recovery policy for unexpected application exits
Invoke-Nssm @("set", $ServiceName, "AppThrottle", "1500")
Invoke-Nssm @("set", $ServiceName, "AppExit", "Default", "Restart")
Invoke-Nssm @("set", $ServiceName, "AppRestartDelay", "5000")

# Restart the service every 30 minutes, even while the application remains healthy
$powerShellExecutable = Join-Path $env:SystemRoot "System32\WindowsPowerShell\v1.0\powershell.exe"
if (-not (Test-Path -LiteralPath $powerShellExecutable -PathType Leaf)) {
    throw "Windows PowerShell not found: $powerShellExecutable"
}
$restartTaskArguments = '-NoProfile -NonInteractive -Command "& {{ Restart-Service -Name ''{0}'' -Force -ErrorAction Stop }}"' -f $ServiceName
$restartTaskAction = New-ScheduledTaskAction `
    -Execute $powerShellExecutable `
    -Argument $restartTaskArguments
$restartTaskTrigger = New-ScheduledTaskTrigger `
    -Once `
    -At (Get-Date).AddMinutes($RestartIntervalMinutes) `
    -RepetitionInterval (New-TimeSpan -Minutes $RestartIntervalMinutes)
$restartTaskPrincipal = New-ScheduledTaskPrincipal `
    -UserId "SYSTEM" `
    -LogonType ServiceAccount `
    -RunLevel Highest
$restartTaskSettings = New-ScheduledTaskSettingsSet `
    -StartWhenAvailable `
    -MultipleInstances IgnoreNew `
    -ExecutionTimeLimit (New-TimeSpan -Minutes 5)

$restartTask = New-ScheduledTask `
    -Action $restartTaskAction `
    -Trigger $restartTaskTrigger `
    -Principal $restartTaskPrincipal `
    -Settings $restartTaskSettings `
    -Description "Restart service $ServiceName every $RestartIntervalMinutes minutes."

Register-ScheduledTask `
    -TaskName $RestartTaskName `
    -InputObject $restartTask `
    -Force | Out-Null

Write-Host "Starting service: $ServiceName"
Invoke-Nssm @("start", $ServiceName)

Start-Sleep -Seconds 3
$service = Get-Service -Name $ServiceName
$registeredRestartTask = Get-ScheduledTask -TaskName $RestartTaskName -ErrorAction Stop

if ($registeredRestartTask.State -eq "Disabled") {
    throw "Scheduled task $RestartTaskName is disabled."
}

$restartInterval = $registeredRestartTask.Triggers[0].Repetition.Interval
if ($restartInterval -ne "PT30M") {
    throw "Invalid restart interval for $RestartTaskName`: $restartInterval"
}

Write-Host "Installation completed successfully."
Write-Host "Service name: $ServiceName"
Write-Host "Current status: $($service.Status)"
Write-Host "Executable: $InstalledExecutable"
Write-Host "Scheduled task: $RestartTaskName"
Write-Host "Next restart: $((Get-ScheduledTaskInfo -TaskName $RestartTaskName).NextRunTime)"
Write-Host "The service is standalone, recovers from unexpected exits, and restarts every $RestartIntervalMinutes minutes."
08 / Troubleshooting

Fast diagnosis

The service remains pending deletion

Close Services consoles and other open service handles. If the bounded timeout expires, reboot during an approved maintenance window.

The service starts and stops immediately

Run the executable interactively under equivalent permissions, inspect stderr and SCM events, and verify working-directory assumptions and runtime dependencies.

No log files are created

Confirm AppStdout/AppStderr values, directory existence, and write permissions for the service identity.

The application cannot access the share

LocalSystem normally authenticates to network resources as the machine account. Use a dedicated identity with explicit least-privilege access or stage artifacts separately.
